# V2 - Hoja de ruta

Esta rama `codex/v2-director-obra` es la base de la segunda version.

## Objetivo

Convertir la app actual en una plataforma mas solida para:

- director de obra / arquitecto
- clientes
- empresas y oficios
- proveedores

## Prioridades

1. Limpiar y modularizar la base actual.
2. Separar usuarios, empresas, proveedores y proyectos.
3. Preparar acceso por oficio con enlace o usuario propio.
4. Permitir reportes con fotos, estado y certificacion.
5. Dejar la app comoda en movil para uso diario en obra.

## Fases

### Fase 1

- estabilizar la base actual
- corregir textos, responsive y estructura
- mantener demo funcional

### Fase 2

- crear perfil `director de obra`
- crear clientes por director
- relacionar empresas y proveedores de forma global

### Fase 3

- portal de oficio
- trabajos asignados por empresa u oficio
- subida de fotos y partes diarios / semanales
- validacion por director o cliente

### Fase 4

- integracion con enlaces compartibles
- preparacion para envio por WhatsApp
- despliegue online estable

## Primer bloque recomendado

El siguiente bloque de implementacion de V2 deberia ser:

1. panel principal de director de obra
2. ficha de cliente
3. relacion director -> proyecto -> oficios
4. acceso simple para oficio
